# Итоговый вопрос

Программа хранится на диске, но выполняется только из оперативной памяти. Операционная система загружает её туда и управляет этим процессом.

# Контрольные вопросы 

1. Файл программы - это сохранённые данные на накопителе.
Процесс - работающая копия программы, управляемая операционной системой.
2. Процессор не может работать с диском напрямую. RAM - это быстрая «рабочая зона», куда ОС загружает код и данные программы для мгновенного доступа.
3. По вкладке «Службы»: процесс есть в списке, у него уникальный PID, и он потребляет ресурсы ЦП и память (значения не нулевые).
4. Программа выполняет циклы с математикой без пауз и ожиданий, заставляя процессор непрерывно считать.
5. Да. Процесс - это временная копия в RAM. При завершении он уничтожается, но исходный файл на HDD/SSD остаётся нетронутым.

# Итоговый вывод

Программа хранится на накопителе в виде пассивного файла с инструкциями, который сам по себе ничего не выполняет. При запуске операционная система загружает этот файл в оперативную память, так как процессор не может работать с диском напрямую из-за огромной разницы в скорости. В RAM создаётся процесс - активная копия программы, которой выделяются собственные адреса памяти, потоки и PID. Именно процесс получает доступ к процессору, который начинает выполнять инструкции из оперативной памяти, производя вычисления. После завершения работы процесс уничтожается, оперативная память освобождается, но исходный файл на диске остаётся неизменным.
